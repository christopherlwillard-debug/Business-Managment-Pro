1416 - Dashboard & Accounting Organization Cleanup

What & Why

Organization and usability improvement only.

Do NOT redesign the application.
Do NOT add new APIs.
Do NOT change calculations.
Do NOT change business logic.
Do NOT remove existing functionality.

The goal is to eliminate duplicate information, group related information together, reduce scrolling, and make the Dashboard the primary business command center with a logical top-to-bottom workflow.

Dashboard Layout

Reorganize the Dashboard into the following sections in this exact order:

1. Quick Actions
2. Today's Alerts
3. Business Overview
4. Revenue vs Expenses
5. Profit
6. Subcontractor Payments
7. My Pay

------------------------------------------------------------

Section 1 – Quick Actions (NEW)

Add a new Quick Actions section directly below the Dashboard header.

This section provides one-tap access to the most commonly used daily actions using existing functionality only.

Display as a clean 2×2 grid of large, touch-friendly cards.

Actions

• Scan Receipt
Launch the existing AI Receipt Scanner.

Description:
Scan a receipt and let Willard AI automatically create the expense.

• Add Expense
Launch the existing manual Add Expense screen.

Description:
Quickly record an expense without scanning a receipt.

• New Job
Launch the existing New Job workflow.

Description:
Create a new job.

• Record Owner Pay
Launch the existing Owner Pay dialog.

Description:
Record an owner draw or compensation.

Design Requirements

• Large touch-friendly cards
• Equal-sized cards
• Rounded corners matching the Dashboard
• Icon above the title
• Optional one-line description
• Clean spacing
• Responsive layout
• No new APIs
• No new business logic

Future Proofing

Build the Quick Actions component so additional actions can be added later without redesigning the component.

Possible future actions include:

• Create Invoice
• Route Planner
• Add Customer
• Banking
• Reports
• Knowledge Base

Do NOT implement these now.
