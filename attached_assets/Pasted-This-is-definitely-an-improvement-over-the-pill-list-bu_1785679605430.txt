This is definitely an improvement over the pill list, but there are still a few things that make it feel "homemade" instead of professional.

1. The map itself

This is the biggest issue.

The state shapes are incorrect. Illinois, Indiana, and Kentucky look like rectangles instead of actual state outlines.

A professional builder (Wix, Squarespace, Framer) would use a real SVG US map with accurate state boundaries.

I'd have Replit replace this with a proper vector map—not a simplified polygon map.
