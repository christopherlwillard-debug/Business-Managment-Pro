I'd actually make this a template, not a theme.

A theme changes the visual design (colors, fonts, buttons, spacing, cards, shadows, etc.).

A template changes the actual page layout and sections. The design you showed isn't just a color change—it's a completely different website structure.

This is what I'd send Replit:

Phase 4 – Premium Website Template System
What & Why

The Theme system already exists and controls colors, typography, buttons, spacing, cards, and other visual styling.

This task does not replace or duplicate that system.

Instead, introduce a Template System that defines the structure, layout, default sections, imagery, and component arrangement of a website while continuing to use the existing Theme system for styling.

A template should feel like starting from a professionally designed website rather than a blank page. Contractors should be able to select a template and immediately have a polished, industry-specific website that only requires replacing text and images.

Golden Rule: Reuse every existing Website Studio component whenever possible. Extend existing components instead of rebuilding them. Do not duplicate rendering logic that already exists.

Phase 4 Golden Rule

This is the most important part:

Never rebuild components that already exist.

Every milestone should extend existing components.

For example:

Hero → add layouts
Services → add presentation modes
Gallery → add new display modes
Coverage Map → add new render modes
Footer → add blocks
Contact → add layouts
Logo Grid → add options

If the component already exists, enhance it. Do not create a second version.

What Comes After Phase 4?

Once Phase 4 is complete, BuildPro has a polished library of premium, reusable components. That sets up a natural roadmap for later phases:

Phase 5: AI Website Generation (generate an entire contractor website from business information using the existing templates and components).
Phase 6: Marketing & Conversion Tools (SEO, landing pages, promotions, review widgets, analytics, A/B testing, lead capture).
Phase 7: Advanced Client Experience (customer portals, project timelines, appointment scheduling, financing, live chat, document sharing).

That progression keeps BuildPro focused on enhancing the foundation you've already built instead of constantly replacing it.
