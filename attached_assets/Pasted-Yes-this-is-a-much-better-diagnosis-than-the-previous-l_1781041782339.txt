The plan you've written identifies the likely root cause correctly:

Problem 1: specialContent only renders in the Content tab

If CardItemEditorPanel is being passed as specialContent but InspectorPanel.tsx only renders it inside:

if (activeTab === "content") {
  return renderContentTab();
}

then the card editor will never appear when the user is on:

Quick
Style
Layout
Advanced

which is exactly what your screenshot shows.

Problem 2: Card click isn't activating the parent section

If:

setSelectedCardState(cardId)

runs but:

setActiveSection(sectionId)

does not,

then the inspector may still think nothing is selected at the section level and fail to render the card editor.

One improvement I'd add to #817

Add a forced tab reset when a card is selected:

if (selectedCardId) {
   setActiveInspectorTab("content");
}

Not because the card editor depends on the Content tab anymore, but because users mentally expect:

Click card
See editing controls

If they were previously buried in Advanced or Style, the UI can feel inconsistent.
