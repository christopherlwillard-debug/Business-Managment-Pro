I actually agree with Replit's recommendation, but I'd change the order slightly.

I would not start with AI.

I would not start with portfolio automation.

I would not start with service synchronization.

None of those matter if the editor still feels like an admin panel.

Phase 1 should be one goal:

Make users forget they're inside BuildPro.

When someone clicks Studio, it should feel like they launched an entirely different application.

Here's the roadmap I'd give Replit.
Phase 1 – BuildPro Studio 2.0 (Immersion)

This phase is 100% UX. No new business features.

1. Studio Mode
Collapse the left BuildPro navigation into an icon rail (or auto-hide it).
Expand the canvas to nearly full width.
Dark charcoal workspace around the page.
Floating page centered with a subtle shadow.
Large, distraction-free editing experience.

This alone will make the editor feel twice as professional.

One thing I would add that neither you nor Replit mentioned...
Introduce "Design Mode" vs. "Content Mode"

Right now, every click feels the same.

Instead:

Content Mode

Edit text.
Replace images.
Change buttons.
Update phone numbers.
Edit forms.

This is what 95% of users need.

Design Mode

Move sections.
Adjust spacing.
Colors.
Typography.
Layout.
Flexbox.
Responsive settings.

That separation dramatically simplifies the experience. Most business owners never need to think about padding, margins, or breakpoints when they're just updating a headline or swapping a photo.

BuildPro already knows the business.

The website becomes a living extension of the business, not a separate project users have to remember to update.

That's the direction I'd encourage Replit to take. It transforms the website builder from "another feature" into a true advantage of the entire BuildPro platform.
