Easy Way to Build It

Use Twilio for SMS.

Your checklist completion function would:

const completedItems = checklist.filter(i => i.completed).length;
const totalItems = checklist.length;
const percent = Math.round((completedItems / totalItems) * 100);

if (percent >= 25 && !job.sent25Percent) {
  sendText(customerPhone, message);
}

Twilio usually costs around:

About $1/month per phone number
Roughly $0.007–$0.01 per text

For your volume, you'd likely spend less than $10/month.
