I agree. Looking at your screenshot, I don't think the problem is that it lacks features—it's that it asks the user to think like a website developer instead of a business owner.

If your target user is someone like you (a contractor), the editor should feel more like editing a Word document than configuring CSS.

I would completely rethink the editing workflow.
1. When you click a section, edit the content first ⭐⭐⭐⭐⭐

Right now if you click the Hero, you're immediately presented with:

Typography
Colors
Backgrounds
Borders
Shadows
Layout
Advanced

That's overwhelming.

Instead, when you click a Hero section, the right panel should start with exactly what people expect:

Hero Banner

Headline
[_____________________]

Subheading
[_____________________]

Button Text
[_____________________]

Button Link
[_____________________]

Hero Image
[ Change Image ]

✓ Show Button
✓ Show Headline
✓ Show Subheading

Only after that should there be a collapsed Design section.

2. Make editing happen directly on the page ⭐⭐⭐⭐⭐

Instead of hunting through a sidebar:

Click the heading.

Type.

Done.

Click the paragraph.

Type.

Done.

Click the button.

Change the text.

Done.

Images:

Hover.

🖼 Change Image

Click.

Choose image.

Done.

That's how Wix, Squarespace, and Shopify make editing feel easy.

3. Make every section have the same layout ⭐⭐⭐⭐⭐

No matter which section you click, the editor should always follow the same pattern:

CONTENT

Images

Buttons

Visibility

----------------

STYLE

Colors

Spacing

Alignment

----------------

ADVANCED

Animations

Custom Classes

etc.

Users learn one pattern instead of relearning every section.

4. Remove 80% of the visible controls

Most people never change:

shadows
borders
padding
advanced layout

Hide them.

If someone wants them:

▼ Advanced Design
5. Replace the left sidebar with something simpler

Instead of:

Header

Hero

Services

Portfolio

About

Contact

Footer

Show:

🏠 Home

Hero Banner

Services

About Us

Portfolio

Contact Form

Footer

+ Add Section

No extra clutter.

6. Make adding sections visual

Instead of:

Services

Testimonials

FAQ

Show cards:

┌─────────────┐
│ Hero Banner │
│  preview    │
└─────────────┘

┌─────────────┐
│ Before/After│
│  preview    │
└─────────────┘

People recognize layouts much faster than names.

7. Add a floating toolbar

When hovering a section:

✏ Edit

⬆ Move

⬇ Move

📄 Duplicate

🗑 Delete

No tiny icons to hunt for.

8. Separate Content from Theme

Your top bar should be:

Editor | Theme | Media | Settings

Editor

Edit the page.

Theme

Colors
Fonts
Buttons

Media

Images

Settings

SEO
Domain
Analytics

Those are completely different tasks.

The biggest thing I'd change

Right now the editor feels like you're configuring a website.

It should feel like you're editing your own website.

Those are very different experiences.

If I were redesigning this from scratch, I'd use one guiding principle:

If a contractor who has never built a website before can't figure out how to change a picture or edit text within 30 seconds, the UI is too complicated.

That's the standard I'd aim for.

I think this is worth treating as a dedicated redesign rather than a series of small tweaks. A focused Website Editor UX Overhaul that prioritizes simplicity and direct editing would have a much bigger impact than adding more features.
