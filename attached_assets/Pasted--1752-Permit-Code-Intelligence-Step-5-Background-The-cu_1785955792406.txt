#1752 - Permit & Code Intelligence (Step 5)

Background

The current Step 5 permit checklist is too static. Instead of simply displaying permit names, Step 5 should become an intelligent planning tool that helps contractors understand permit requirements, inspection requirements, code considerations, and project risks before work begins.

The goal is not simply to ask "Do I need a permit?" but to help contractors avoid missing requirements that could delay a project or cause failed inspections.

Permit & Code Intelligence
