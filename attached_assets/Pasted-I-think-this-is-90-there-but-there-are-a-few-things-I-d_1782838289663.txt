#1057 - Simplify Manufactured Home Production Job Workflow

What & Why

The Manufactured Home Production job form has gradually become too complicated. Creating a new Production job requires too many steps, exposes too many management features, and forces the user into screens that should only be used for administration.

The goal is to make creating a Production job fast and intuitive.

A Production job should follow the natural workflow used in the field:

Select (or create) the Builder.
Select (or create) the Model.
Select the Construction Type.
Select the Production Services included.
Create the job.

The user should never need to leave the job form just to create a Builder or Model.

The Home Library should become a management/reference area rather than part of the everyday Production job workflow.

Design Philosophy

The Production job form should collect only the information needed to describe the job.

It should not attempt to automate invoices, pricing, checklists, or estimating.

The owner prefers to build invoices manually.

Production Services exist only to describe what work was included on the job and provide better filtering, reporting, and historical records.

The workflow should reduce clicks and eliminate unnecessary navigation.

One thing I'd change from your current task

I would remove this sentence:

"Construction Type lives on the model, not the job..."

That describes the current implementation rather than the new design. The task should describe the desired state, not why the old one was confusing.

I also would remove any mention of automatically building invoices. Based on what you've told me, that's not how you want to work anymore. Keeping Production Services as simple, reusable labels makes the workflow cleaner and gives you flexibility without unnecessary automation. I think this version better matches how you actually run your business every day.
