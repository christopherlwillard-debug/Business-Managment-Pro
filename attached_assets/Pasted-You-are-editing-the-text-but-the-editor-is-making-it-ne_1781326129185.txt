I would create a ticket specifically for text editing

#836 - Improve Inline Text Editing UX

Done Looks Like

Double-clicking any heading, paragraph, or button text enters edit mode immediately.
A visible text cursor appears inside the text.
Selected text receives a subtle outline while editing.
Formatting toolbar appears above the selected text instead of covering it.
Text remains fully visible while editing.
Pressing Enter commits changes.
Pressing Escape exits editing mode.
Inspector automatically switches to the Content tab when a text element is selected.
Users never need to hunt through the right panel to change simple text.
For your immediate issue

Try this:

Click the Content tab in the inspector (you're currently on Layout).
Look for:
Title
Heading
Hero Title
Main Headline
Edit it from there.

If nothing appears under Content, then the editor likely doesn't have a proper content-binding system yet and is relying entirely on inline editing.

Another thing I notice

Your heading is getting cut off:

Specializing In Manufact...

That usually means either:

Max width is too narrow
Container width is constrained
Text overflow is being clipped

Heading text should automatically wrap to multiple lines instead of clipping or truncating.
