Those four changes are actually much more targeted than some of the earlier ideas.

Looking at your screenshot, I'd rank them like this:

1. Remove the Desktop / Tablet / Mobile columns (Highest Impact)

This is the biggest waste of space I see.

Right now every field is:

Padding Top      [Desktop] [Tablet] [Mobile]
Padding Right    [Desktop] [Tablet] [Mobile]
Padding Bottom   [Desktop] [Tablet] [Mobile]

But Tablet and Mobile aren't even functional yet.

Instead:

Padding Top
[ slider ]

Padding Right
[ slider ]

Much cleaner.

I'd go even further:

Hide responsive controls entirely until responsive editing is actually implemented.

Then later:

Responsive Mode
○ Desktop
○ Tablet
○ Mobile

at the top of the editor.

2. Accordion Sections (Huge Improvement)

Your screenshot is basically one giant scrollable form.

This:

▼ Alignment
▼ Width
▼ Spacing
▼ Sizing

is exactly how most builders handle it.

I would make:

Alignment

expanded by default

and everything else collapsed.

Most users aren't adjusting min-height every time they click a section.

3. Inspector Width Reduction (Good)

300 → 260 px is reasonable.

I wouldn't go much smaller than 260 though.

Below that:

labels wrap
sliders get cramped
typography controls become annoying
4. Structure Panel Visibility (Good)

I noticed in your screenshot the collapse control is technically there, but it doesn't draw attention.

I'd make it much more obvious:

☰ Structure

or

◀ Hide Structure

When collapsed:

▶
One More Change I'd Add
Auto-switch Inspector Tabs

If you click:

Heading → Content tab
Image → Style tab
Section → Layout tab

Right now you're editing a Hero Banner and immediately dropped into Layout.

Most people editing a Hero are trying to change:

headline
button text
image

not padding.

That alone would make the editor feel smarter.

Overall

If Replit implements those four changes:

Remove responsive placeholder columns
Accordion groups
Narrower inspector
Better structure collapse

I think you'll immediately notice a much cleaner editor.

The screenshot doesn't look crowded because the website is too big—it looks crowded because the inspector is showing every possible control at once, including controls that don't actually work yet. Removing those placeholder responsive columns and collapsing unused sections will probably give you more usability improvement than another round of canvas resizing.
