I agree with your note at the end. I would not tell Replit to "rewrite Dashboard.tsx" or "rebuild the Home Dashboard." That's exactly how features get broken.

I'd change the task to something like this:

Goal

Upgrade the existing dashboard into the V2 Business Command Center without replacing or rewriting working code.

Preserve all existing APIs, hooks, routing, permissions, business logic, calculations, and components whenever possible.

The objective is to improve layout, hierarchy, and presentation—not rebuild functionality.

Development Rules (Important)
Do NOT rewrite Dashboard.tsx from scratch.
Do NOT remove existing working components.
Reuse every existing data hook that already provides the needed data.
Only create new APIs when information truly does not already exist.
Prefer rearranging existing sections over replacing them.
Preserve all navigation behavior.
Preserve all existing calculations.
Keep all styling changes isolated so future dashboard updates remain easy.
Make the smallest possible code changes required to achieve the V2 design.
