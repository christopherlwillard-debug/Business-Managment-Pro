Use modern React component architecture and store all styling settings as JSON so every customization persists when saved.

Then after that is working, I’d give it another prompt:

Refactor the builder so every block uses a universal property system. All blocks should support backgrounds, spacing, animations, visibility settings, responsive settings, and custom CSS classes through the same shared configuration structure.

That second prompt is important because it prevents you from having to add background controls, padding controls, etc. separately to every component in the future.

Long term, what you really want is:

* A Block Library (Hero, Gallery, Contact, Testimonials, FAQ, Pricing, Map, Reviews)
* A Property Panel (edit everything)
* A Theme System (change an entire site’s look with a few clicks)

Once those three pieces exist, you’re much closer to a Wix-style builder than a basic drag-and-drop page editor.
