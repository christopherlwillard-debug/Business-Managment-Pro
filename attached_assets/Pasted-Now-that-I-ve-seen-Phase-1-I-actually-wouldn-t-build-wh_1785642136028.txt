#1458 – BuildPro Studio 2.0: Direct Editing Experience
Design Principles

The canvas is no longer just a preview—it is the editor.

Users should be able to build an entire website while rarely interacting with the inspector.

The inspector becomes a secondary tool for advanced styling and configuration.

Every common action should require one click or less to discover.

What & Why

Phase 1 transformed Studio into a professional workspace.

Phase 2 transforms Studio into an editor that feels effortless to use.

The focus is not adding new capabilities—it is making existing capabilities discoverable, intuitive, and available directly on the canvas.

The user should never wonder:

"Where is that setting?"

The answer should almost always be:

"Click the thing you want to change."

Success Metrics

A new user should be able to:

Replace any image without opening the inspector.
Change any heading by simply clicking it.
Edit any button directly on the canvas.
Move sections without reading documentation.
Add new content in under 30 seconds.
Understand how to edit the website without watching a tutorial.

If a user opens the inspector for a common task, the UX should be reconsidered.

Why I think this is the right Phase 2

Looking at your completed Phase 1, you've already achieved the "looks like a design app" milestone. The next thing a first-time user will judge isn't the visuals—it's whether they can instinctively figure out how to change text, replace an image, move content, or insert something new.

If Phase 1 made Studio look like Wix Studio, Phase 2 should make it feel like Wix Studio. That shift—from relying on side panels to interacting directly with the page—is what will make BuildPro Studio feel natural to use.
