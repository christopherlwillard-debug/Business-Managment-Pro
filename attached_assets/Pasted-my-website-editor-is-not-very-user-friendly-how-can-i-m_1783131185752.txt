my website editor is not very user friendly how can i make it better

Looking at your screenshot, I think the biggest issue isn't the features—it's the information density. There are too many controls visible at once, so it's hard to focus on editing the website itself.

Here are the biggest improvements I'd make.

1. Make the canvas the hero ⭐⭐⭐⭐⭐

Right now the page is roughly:

Left sidebar: ~20%
Canvas: ~50%
Right inspector: ~30%

The website you're building only gets about half the screen.

I'd make it more like:

------------------------------------------------------------
| Left Structure |          Website Canvas        | Inspector |
|     220px      |            Flexible            |   320px   |
------------------------------------------------------------

The canvas should always get the remaining space.

2. Move the Theme settings out of the editor ⭐⭐⭐⭐⭐

The left panel is mixing two completely different jobs:

Site Structure
Theme Editor

Those shouldn't be together.

Instead:

Editor
Media
Theme
Pages
Analytics

Clicking Theme opens:

Colors
Fonts
Buttons
Cards
Forms

Those are global settings, not page editing.

That alone removes half the clutter.

3. Only show inspector controls that matter ⭐⭐⭐⭐⭐

Right now selecting the Hero shows:

Quick
Content
Style
Layout
Advanced

Most users only use Content.

I'd make:

Content
Style

▼ Advanced

Hide the advanced stuff until needed.

4. Better section controls

Instead of tiny floating icons:

✏
↑
↓
📋
🗑

Show a cleaner toolbar:

Edit
Duplicate
Move
Delete

or even a three-dot menu.

5. Add breadcrumbs

Instead of only:

Hero Banner

show:

Home
>
Hero Banner

Makes navigation much easier.

6. Collapse everything by default

I counted a lot of expanded accordions.

Instead:

Typography >

Colors >

Background >

Borders >

Spacing >

Animation >

Only open what the user clicks.

7. Make Add Section visual ⭐⭐⭐⭐⭐

Instead of a text list:

FAQ

Like Webflow or Squarespace.

8. Right-click sections

Instead of hunting icons:

Right click:

Duplicate

9. Better page tree

Instead of:

Home

Much easier to scan.

10. Split editing into modes ⭐⭐⭐⭐⭐

Instead of every setting always visible:

Content Mode

Only edit:

text
images
buttons
Design Mode

Only edit:

colors
spacing
typography
Structure Mode

Only:

reorder
duplicate
add sections

Most users spend 90% of their time in Content mode.

11. Bigger section outlines

The blue overlays are hard to see.

Instead use:

──────────────────────────
 HERO BANNER

──────────────────────────

When hovered.

12. Improve the left sidebar

Right now:

Site Structure

Much cleaner.

If this were my app...

I'd redesign it around three workspaces:

1. Content (default)
Large canvas
Site structure on the left
Simple content editor on the right
2. Theme
Colors
Fonts
Buttons
Cards
Forms
Layout
3. Pages
Add/delete pages
Navigation
SEO
Domain
Analytics

The current editor tries to expose every setting at once, which makes it feel overwhelming. Separating content editing from theme customization would make the interface much more approachable while still keeping all of the advanced controls available when needed. I think that single change would have the biggest impact on usability.
