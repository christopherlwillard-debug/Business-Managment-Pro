The current editor is actually well-built underneath — 53 files, ~24k lines, already has drag-and-drop (dnd-kit), inline text editing, undo/redo, context menus, and an inspector. The hard infrastructure is there. What makes it feel like a "settings panel" instead of a professional tool is the shell — layout, dark canvas, hover controls, floating toolbar.

Here's how hard the specific improvements are:

Quick wins (a day or two each):

Dark editor background — the website floats on a charcoal canvas like Framer/Figma. Mostly CSS.
Hover-only section controls — show Move/Duplicate/Hide/Delete only on hover, not as permanent buttons. EditableWrapper.tsx is the right place.
Section library gallery — clicking "Add Section" slides open a visual grid of templates with thumbnails instead of a plain list. sectionTemplates.ts already has the data.
Floating text toolbar — bold/italic/link/align appears above the text you're editing instead of in the right sidebar.
Medium effort (a few days each):

Figma-style left navigator — expandable layer tree (Home → Header → Logo, Nav, CTA). The section tree exists; it needs a proper tree component.
Context-aware inspector — right panel changes completely based on what's selected (text → typography panel, image → image panel, button → button panel). The inspector already detects element type; it needs the panels fleshed out.
AI content generation — right-click any section → "Rewrite with AI." OpenAI is already wired into this project.
Heavy lift (weeks, significant architecture changes):

Element-level drag-and-drop (drag a button, image, or text block within a section). Section reorder is done; element reorder inside sections is a different beast.
True responsive breakpoints — independent mobile/tablet/desktop editing. The data model has a breakpoints field but it's not fully wired.
Full flexbox layout builder (Figma-style grow/shrink/gap controls per element).
My honest take: The single highest-impact thing you could do — the one that changes how it feels the most — is the visual shell redesign: dark canvas, hover controls, floating toolbar, and a better section library.
