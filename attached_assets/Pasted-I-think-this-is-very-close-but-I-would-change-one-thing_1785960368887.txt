One requested change:

Do not name the database table "owner_withdrawals."

Instead, use a more generic name such as:

- owner_distributions
- profit_distributions
- equity_distributions

The accounting engine already supports multiple business entity types, so the data model should remain entity-agnostic.

For a Sole Proprietorship or Single-Member LLC, these records represent Owner Draws.

For Partnerships, they represent Partner Distributions.

For S Corporations, they can represent Shareholder Distributions.

This avoids future database migrations as additional entity types are supported.
