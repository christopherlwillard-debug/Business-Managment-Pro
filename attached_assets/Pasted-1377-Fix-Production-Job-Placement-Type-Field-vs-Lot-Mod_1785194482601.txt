1377 - Fix Production Job Placement Type (Field vs Lot Model)

What & Why

The current Manufactured Home section only asks for the home's Construction Type (VOG, Hybrid, or Drywall). This is incomplete because there are actually two separate characteristics that determine production pricing:

1. Where the work is being performed.
2. How the home is constructed.

Today, the system incorrectly treats "Lot" as if it were a construction type. It is not.

A Lot Model is simply a home that is being finished on a dealer or manufacturer lot before delivery. It can still be built as a VOG, Hybrid, or Drywall home.

Likewise, a Field Job is a home being finished after delivery to the customer's property, and it can also be VOG, Hybrid, or Drywall.

Because of this, pricing cannot be determined from only one selection.

The user must first choose:

• Field
• Lot Model

Then choose:

• VOG
• Hybrid
• Drywall

This creates six valid pricing combinations instead of four.

Business Logic

Every Production job has two independent attributes.

Placement Type

• Field
• Lot Model

Construction Type

• VOG
• Hybrid
• Drywall

These combine into the following pricing matrix.

Field + VOG
→ priceVog

Lot Model + VOG
→ priceLotVog

Lot Model + Hybrid

Lot Model + Drywall

The previous implementation of a single "Lot" price column is incorrect because it assumes every lot model home has the same construction type.

Why This Design

The placement type answers:

"Where is the work being performed?"

The construction type answers:

"How is the home built?"

These are two completely different pieces of information and should never be combined into a single selection.

A Lot Model is not a construction type.

A VOG home can be a Field Job or a Lot Model.

A Hybrid home can be a Field Job or a Lot Model.

A Drywall home can be a Field Job or a Lot Model.

Separating these selections makes the interface much easier to understand, accurately reflects how manufactured home work is performed, and allows the billing engine to select the correct one of the six available pricing columns.
