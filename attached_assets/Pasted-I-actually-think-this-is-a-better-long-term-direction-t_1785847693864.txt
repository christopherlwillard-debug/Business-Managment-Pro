Phase 5 — AI Website Builder (Not Website Analyzer)
What & Why

BuildPro already contains a Website Studio, Theme System, Component Library, business data, CRM, media library, service catalog, and design controls. The next step is not another analysis panel—it is an intelligent website builder.

The AI should function as an experienced web designer that works inside Website Studio rather than outside of it. It should create, modify, rearrange, and improve websites using only existing BuildPro components and settings.

Golden Rule: Never generate custom HTML or create a second rendering system. The AI must only use the same components, properties, layouts, and controls available to the user. Every AI change remains fully editable through the existing Website Studio.

One feature I would add before all of this

If BuildPro is going to feel like a professional design tool, I'd add a Canvas Edit Mode that works much like Figma or Canva.

When you click any element (text, image, logo, button, card, icon), it gets resize handles and alignment guides. You could:

Drag to reposition within its container (respecting the layout system).
Resize images and logos visually instead of typing pixel values.
Drag spacing between elements with smart guides.
Snap to grids and alignment lines.
Right-click for common actions (Duplicate, Replace, Ask AI, Hide, Delete).

That complements the AI perfectly:

Manual: "I'll move this exactly where I want."
AI: "Make this section look more premium."

Those two workflows reinforce each other instead of competing. The AI does the heavy lifting, and the canvas gives the user precise control to fine-tune the result.
