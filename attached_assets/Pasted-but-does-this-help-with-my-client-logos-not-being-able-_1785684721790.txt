Epic #1516 - Universal Direct Editing Experience
What & Why

The website builder should feel like Canva, Framer, or Webflow—not like editing a settings form.

Today, many elements require users to hunt through the inspector to make changes, while others aren't editable at all. Every visible element should be directly interactive on the canvas.

The goal is simple:

If you can see it, you can click it.

Every section should use the same editing experience so users never have to guess how to modify something.

Core Principles
Every visible element is clickable.
Hovering any editable element highlights it.
Clicking selects the element and opens the correct inspector.
Text edits inline using InlineEditableText.
Images open the Media Library.
Icons open the Icon Picker.
Buttons open Button Settings.
Logos open the Logo Picker.
Backgrounds open Background Settings.
Empty placeholders are clickable.
