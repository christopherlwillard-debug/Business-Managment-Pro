UX Improvements

I'd also add a few quality-of-life features that people expect in premium builders:

Right-click context menu anywhere on the canvas (Edit, Duplicate, Copy, Paste Style, Delete).
Lock elements so they can't be accidentally moved or edited.
Hide on desktop / tablet / mobile toggles for responsive layouts.
Copy & paste entire sections between pages.
Global undo history with named actions ("Edited Hero Title", "Added Services Section") instead of just undo/redo.
Overall

I genuinely think you're past the "build more sections" phase.

The builder already has a solid foundation. What will separate BuildPro from Wix, Squarespace, or GoDaddy isn't having 10 more sections—it's making the editing experience feel effortless.

If I had to prioritize the next wave of work, I'd rank it like this:

Fix every broken interaction (Add Logo, image uploads, clickable elements).
Universal direct editing ("If you can see it, you can edit it").
Redesign the footer into block-based columns.
Improve spacing, hover states, and visual polish.
Add high-conversion sections like FAQ, Meet the Owner, and How We Work.

At that point, BuildPro starts feeling less like a collection of configurable components and more like a polished, professional website builder designed specifically for contractors—which is exactly the niche you're targeting.
