Yes. Looking at your screenshots, the biggest problem isn't the features anymore—it's screen real estate and panel density.

You've actually reached the point where you're suffering from the same problem early versions of Webflow had:

Too many controls visible at once and not enough focus on the website.

What I would change immediately
1. Make the right inspector FULL HEIGHT with independent scrolling

Right now:

Inspector
├─ Search
├─ Tabs
├─ Controls
├─ Controls
├─ Controls
├─ Controls
└─ Cut off

Instead:

┌───────────────────┐
│ Search            │
│ Tabs              │
├───────────────────┤
│                   │
│ Scroll Area       │
│                   │
│                   │
│                   │
└───────────────────┘

Only the inspector contents should scroll.

Not:

page
canvas
inspector

all together.

2. Collapse sections by default

Instead of:

TEXT CONTENT
IMAGE
LINK
BACKGROUND
PADDING
ALIGNMENT
WIDTH
VISIBILITY

Make them:

▸ Content
▸ Design
▸ Layout
▸ Advanced

Open only one at a time.

This alone cuts visual clutter by 70%.

3. Make the Site Structure narrower

Your left panel is wasting space.

Current:

Home
  Header
  Hero Banner
  Image
  Services
  About
  Contact
  Footer

takes huge vertical space.

Instead:

▾ Home
   Hero
   Image
   Services
   About
   Contact

with 28-32px row heights.

You can easily reclaim another 50-80px.

4. Auto-hide inspector when nothing selected

When no section is selected:

Site Settings
Theme
Pages
SEO

When section selected:

Inspector

When card selected:

Card Editor

No mixed modes.

This would be massive.

Instead of always using the sidebar:

When a card is selected:

✏ Edit
🎨 Style
📷 Image
📋 Duplicate
🗑 Delete

right above the card.

80% of edits never touch the sidebar.

7. Increase canvas width

This is the biggest issue visually.

Your builder currently looks like:

[Tree][Canvas][Inspector]
 20%    60%      20%

I would move toward:

[Tree][Canvas][Inspector]

[Tree][Canvas][Inspector]
 12%    76%      12%

The website should dominate the screen.

The editor should feel like:

"I'm editing a website"

not

"I'm editing settings."

Webflow does this really well.

450px
