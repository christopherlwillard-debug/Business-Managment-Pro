#1869 - Fix Sub Payout Status: Dashboard + Jobs Page

What & Why

The Dashboard shows “Subs Need Paid — $820.00” and the Jobs page shows “Needs Payout 2” even though the Sub Balances screen shows all subs are fully settled.

The three surfaces are currently reading from inconsistent sources:

* Sub Balances (correct): /api/subcontractors/outstanding-balances filters by job_subcontractors.paymentStatus IN ('unpaid', 'partial'), so settled rows are excluded.
* Dashboard (broken): reports.ts reads job_subcontractors.amountPaid for ALL rows without filtering by paymentStatus. If amountPaid is stale or zero while paymentStatus = 'paid', the calculation incorrectly shows money still owed.
* Jobs page (broken): Uses expenses?category=Subcontractor plus !job.subPaid. These are stale signals and do not reflect the actual payment ledger.

Single Source of Truth

sub_payment_records / job_subcontractors.paymentStatus must be the authoritative source for subcontractor payout status.

A subcontractor has an outstanding balance only when:

paymentStatus = 'unpaid' OR paymentStatus = 'partial'
AND
owed - paid > 0

A subcontractor with:

paymentStatus = 'paid'

must never inflate the Dashboard’s outstanding amount or cause a job to appear in Needs Payout.

Done Looks Like

Dashboard

The Dashboard “Subs Need Paid” amount reflects only genuine outstanding subcontractor balances from the payment ledger.

When all subs are settled:

* Show $0.00, OR
* Hide the alert row entirely.

It must NOT show the previous false-positive $820.00.

Jobs Page

The Jobs page “Needs Payout” badge:

* Only appears when at least one job has a genuine outstanding subcontractor balance.
* The count matches the number of jobs with an actual outstanding balance.
* The filter only returns jobs with an actual outstanding subcontractor balance.
* Fully settled jobs never appear in the payout filter.

Job Cards

The job card’s “Subs Settled” status must use the same outstanding-balance data as the Jobs badge.

The Dashboard, Jobs page, and Sub Balances screen must all agree.

Historical Expenses

Historical subcontractor expense records in the expenses table are unaffected.

Do NOT delete, alter, or hide legitimate subcontractor expenses.

An accounting expense is not the same thing as an unpaid subcontractor balance.

Out of Scope

* Changes to how subcontractor payments are recorded.
* Changes to the subcontractor payment ledger itself.
* Changes to the Sub Balances tab. It is already showing the correct status.
* Deleting or modifying historical subcontractor expense records.
