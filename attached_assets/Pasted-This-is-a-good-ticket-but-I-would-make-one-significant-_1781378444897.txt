This is a good ticket, but I would make one significant change before submitting it.

Don't use single-click to immediately enter edit mode

In website builders, single-click is often needed for:

Selecting an element
Showing handles
Dragging
Opening inspector settings
Multi-select behavior later

If you make every single click enter typing mode, you'll create new problems.

Instead:

Better behavior

Single Click

Select text element
Show blue outline
Show floating toolbar

Double Click OR Enter

Enter text editing mode
Show cursor
Start typing

This is how Figma, Framer, Webflow, and many design tools behave.
