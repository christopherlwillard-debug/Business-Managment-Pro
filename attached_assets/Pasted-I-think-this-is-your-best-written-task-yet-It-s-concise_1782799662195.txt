Validate that the Builder activation/deactivation feature implemented in #1032 behaves correctly in production.

I'd change it to:

Validate that the Builder activation/deactivation feature implemented in #1032 behaves correctly in the deployed application. Validation should be performed in production when appropriate, or in an equivalent environment if production testing is not yet possible.

That way if production isn't updated yet, they can still complete the validation in a staging or development environment.

2. Add one validation that matters to your business

This is the only thing I think is missing.

Model creation validation

After deactivating a Builder:

New models cannot be added under an inactive Builder.
After reactivation, models can once again be added normally.

Otherwise someone could accidentally keep adding models under an inactive Builder, which defeats the purpose of deactivating it.
