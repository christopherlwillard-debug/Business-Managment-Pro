#1512 - "Meet the Owner" Section
What & Why
There's no dedicated section for the contractor to introduce themselves. For owner-operated businesses — especially veteran-owned contractors — a personal bio section builds trust faster than any service list. The PM feedback specifically called it "perfect for contractors."

Add a new meet-owner section type with a photo, bio, credential badges (Veteran, Licensed, Insured, etc.), years of experience, and a personal quote or tagline.

Done looks like
A new "Meet the Owner" section type appears in the Section Library under a "Team & Story" category
Default layout: photo on the left, name + title + bio + badge pills on the right (responsive: stacks on mobile)
Editable fields: owner name, title/role, bio paragraph, years of experience, photo (via media library), personal quote/tagline, credential badge list (same chips as footer: Veteran Owned, Licensed, Insured, SDVOSB, etc.)
An alternate "centered" layout with a circular portrait above the text for a cleaner minimalist look
The section integrates with InlineEditableText so all text fields are click-to-edit on the canvas
Default placeholder content pre-fills with realistic contractor copy so it looks good out of the box
Out of scope
Multiple team members (that would be a separate "Team/Crew" section)
Video bio
Social links on this section (footer already handles those)
Steps
Create MeetOwnerSection component — build the section component with photo + content layout, using InlineEditableText for name/title/bio/quote and a badge pill list for credentials; support "split" (photo left) and "centered" (portrait above) layout variants
Add media library hook for photo — the photo slot should open the existing media library picker when clicked in edit mode (same pattern used in HeroSection or FeaturedClientsSection)
Register section type — add meet-owner to the Section.type union, SECTION_LABELS, getSectionTypeIcons, renderSection switch, and getAddableSectionTypes in WebsiteEditor.tsx
Default content + template entry — write defaultMeetOwnerContent() and add a "Meet the Owner" entry to the Section Template Library so it shows up in the Add Section drawer

What & Why
Contractors consistently convert better when they show prospects what to expect — a numbered sequence of steps (Get Estimate → Schedule Visit → We Build → You Move In). Add a process section type that renders a numbered step flow with icons, short descriptions, and optional connecting arrows between steps.

Done looks like
A new "How We Work" section type appears in the Section Library
