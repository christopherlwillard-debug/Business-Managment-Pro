## Summary

- **Stale “dead” claims:** all four calculators are imported and rendered; `prospect_events.old_value` is written, returned, and displayed; the material-list tax formula is no longer duplicated in the cited file; the admin migration router is substantially smaller than reported.
- **Current likely cleanup candidates:** the 12 listed UI primitive modules have no current frontend importers; `SCHEDULE_C_LINES` has no current caller. Neither finding authorizes deletion by itself.
- **Financial logic requiring care:** the configurable allocation engine coexists with four hard-coded 5% report paths; allocation arithmetic has both a documented client mirror and remaining direct calculations; `formatCurrency` variants have different input/formatting contracts. Treat these as correctness/reconciliation work, not dead-code deletion.
- **Uncertain schema-only tables:** `conversations/messages`, `featured_clients`, `inquiries`, and `portfolio_photos` have no active ORM caller located in this source pass, but each is still named in the System Registry. Table contents, external consumers, and deployment-specific ownership were not checked. They are not confirmed safe to drop.
- **No dead-code cleanup was performed.** The source review itself did not run tests, builds, API calls, or database queries. The task-completion validator subsequently ran checks: typechecks and the two job-profit checks passed; the API test suite reported 1,436 passed and 6 failed across `accrued-bonus-profit`, `job-production-components`, `reserve-tax-parity`, and `cashbasis-extended`. The failed browser verifiers (`close-job`, `production-presence`, `production-components`, and `component-baseline-reviews`) timed out waiting for Chromium's debugging endpoint. These are application/runtime validation failures, not failures in the report file. The production-components script creates a temporary fixture and calls its cleanup routine from `finally`; the captured log contains no cleanup error. No independent production-data query was made to verify table contents or fixture state.
