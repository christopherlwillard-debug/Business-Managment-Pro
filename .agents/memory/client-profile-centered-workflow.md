---
name: Client profile-centered workflow
description: BuildPro's Client Profile is the customer hub for properties and related work.
---

BuildPro's existing Client Profile should be the central place to manage a customer's properties, measurements, estimates, jobs, recurring services, and related records. Reuse existing domain tables, APIs, and calculation/quote workflows; do not create a standalone Property Library experience or a competing estimating system.

**Why:** The user wants customer work organized around one Client Profile instead of disconnected modules.

**How to apply:** Add profile sections and contextual actions that call the existing property, measurement, pricing, estimate, quote, and job systems. Keep their data models and ownership boundaries separate. Do not change production or accounting workflows as part of this work.
